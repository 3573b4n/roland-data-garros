# 🎾 Roland Data Garros 2026

Dashboard interactivo con datos en vivo de Roland Garros 2026.

## Stack

- **Frontend**: Streamlit
- **Datos**: SQLite + pandas
- **Scraping**: Python + Node.js (extracción Nuxt.js)
- **Hosting**: Hugging Face Spaces

## Actualización de datos

Los datos se actualizan automáticamente cada 15 minutos mediante GitHub Actions.
